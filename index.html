품의 도우미 개인정보처리방침

문서 기준: 2026년 10월 5일 · 적용 버전: 1.0.0
교사가 제작한 비공식 품의 입력 보조 도구입니다.

1. 처리하는 정보와 목적

사용자가 확장프로그램을 열면 현재 탭 주소로 지원 사이트인지 확인합니다. ‘선택한 품목 가져오기’ 또는 ‘장바구니 가져오기 시도’를 누르면 G마켓·11번가·SSG닷컴·아이스크림몰·쿠팡 및 사용자가 요청한 다른 쇼핑몰 장바구니에서 선택한 상품의 이름, 옵션·규격, 수량, 금액, 배송비와 화면상 상품 행 식별자를 읽습니다. 품목명·규격 정리, 예상금액 계산, 사용자가 요청한 K-에듀파인 품목내역 입력에만 사용합니다. 생성 시각, 출처 쇼핑몰, 원래 품목과 올림 적용 상태도 임시 보관합니다.

K-에듀파인에서는 품목 영역, 예산 선택 여부, 요구금액과 입력 결과를 확인합니다. 자동 입력 후 되돌리기 가능 여부를 판단하기 위해 화면 조작 발생 여부와 마지막 입력 묶음의 식별자·행 수·합계를 해당 페이지의 메모리에 유지합니다. 입력 키나 화면 조작 내역을 기록하지 않습니다.

2. 보관 위치와 기간

가져온 품목은 Chrome의 storage.session을 사용하는 확장프로그램 메모리에 보관됩니다. 클라우드 동기화나 개발자 서버 저장은 하지 않습니다. 브라우저 재시작, 확장 관리 화면에서 사용 중지·재로드·업데이트 시 임시 저장 내용은 지워집니다. 사이드패널을 닫는 것만으로는 지워지지 않습니다.

‘상품 비우기’와 확인창의 ‘비우기’을 누르면 가져온 목록을 삭제할 수 있습니다. 새 목록을 성공적으로 가져오면 이전 목록을 대체합니다. 실패 시 이전 목록을 유지합니다. 에듀파인의 ‘입력한 품목 비우기’는 화면의 품목 행만 삭제하며 가져온 목록·제목·개요·예산은 유지합니다. 품목 삭제 확인 기록은 해당 페이지 수명에 한정됩니다.

업데이트 내역을 읽은 버전 번호와 문의 빈도 제한용 무작위 기기 식별자를 storage.local에 저장해 새 업데이트 표시 여부와 문의 빈도 제한에 사용합니다. 상품 데이터와 분리되며 확장프로그램 제거 시 삭제됩니다. 패널 안의 새로고침은 가져온 목록을 삭제하지 않습니다.

3. 외부 전송과 공유

이 확장프로그램은 품목 데이터를 개발자 서버, 분석 서비스, 광고 서비스 또는 AI 서비스로 전송하지 않습니다. 데이터 판매, 광고 목적 이용, 제3자 제공도 하지 않습니다. 다만 사용자가 입력을 실행하면 품목 데이터가 K-에듀파인 페이지의 입력란에 전달됩니다. K-에듀파인 페이지 자체의 통신과 사용자의 저장·결재는 해당 서비스의 정책을 따릅니다.

직접 전송이 연결된 버전에서는 사용자가 ‘문의 보내기’를 누르면 문의 유형·직접 작성한 내용·선택 입력한 답변 이메일·확장 버전·무작위 접수번호와 기기 식별자가 Google Apps Script 서버로 전달됩니다. 서버가 고정된 문의 수신자(byobyossam@gmail.com)에게 메일 발송을 요청합니다. 이메일 본문을 읽는 권한이나 사용자 Google 로그인은 요구하지 않습니다. 서버 운영 계정에는 메일 발송 권한이 필요합니다.

서버는 중복·과다 발송 방지를 위해 해시·접수번호·처리상태·시각·횟수만 스크립트 속성에 보관합니다. 48시간 지난 항목은 다음 접수 시 정리되며 새 접수가 없으면 남을 수 있습니다. 본문·답변 이메일은 별도 데이터베이스나 애플리케이션 로그에 저장하지 않습니다. 문의 메일은 Google의 메일 처리와 문의 수신함에 보관되며 문의 응대에 사용됩니다. 삭제를 원하면 문의 주소로 요청해 주세요.

메일 앱으로 보내기와 복사도 제공됩니다. 이 경우 사용자가 직접 메일을 전송하며 사용 중인 이메일 서비스의 처리 방식이 적용됩니다. 어느 방식이든 페이지 URL·상품·예산·스크린샷을 자동 첨부하지 않습니다. 작성 중인 문의는 패널 메모리에 유지되며 패널 페이지가 종료되면 사라집니다.

4. 처리하지 않는 정보

비밀번호, 인증서, 로그인 쿠키, 카드번호, 계좌번호를 읽거나 저장하지 않습니다. 웹페이지에서 학생 정보, 연락처, 이메일 본문을 자동 수집하는 기능이 없습니다. 방문 기록을 지속적으로 감시하지 않습니다. 별도의 회원가입, 사용 통계, 추적 쿠키가 없습니다.

5. 권한

  • activeTab: 사용자가 확장프로그램을 실행한 현재 탭을 확인하고 일시적으로 접근합니다.
  • scripting: 확장에 포함된 코드로 선택 상품을 읽고 요청한 품목 입력·되돌리기를 수행합니다.
  • storage: 장바구니에서 가져온 품목을 탭을 이동하는 동안 메모리에 임시 보관하고 업데이트 읽음 버전 번호와 문의 빈도 제한용 무작위 식별자를 로컬에 저장합니다.
  • sidePanel: 브라우저 사이드패널에 품의도우미 화면을 표시합니다.
  • 선택적 호스트 접근: script.google.com, script.googleusercontent.com. 사용자가 직접 문의를 보낼 때 서버 요청과 Google 응답 리디렉션을 받는 용도입니다. 거절해도 상품 가져오기·품의 입력 및 메일 앱 문의는 사용할 수 있습니다.

6. 제한적 사용

품의 도우미의 데이터 사용은 Chrome 웹스토어 사용자 데이터 정책과 제한적 사용 요건을 따릅니다. 데이터는 사용자가 요청한 품의 입력 보조 기능에만 사용하며 광고, 데이터 중개, 신용 평가를 위해 이용하거나 이전하지 않습니다.
